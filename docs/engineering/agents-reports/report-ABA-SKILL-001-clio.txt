MAIN RULES CURATED
------------------
- Naming: MixedCaps, lower-case packages (no util/common), Err/err prefix,
  Error suffix, descriptive names throughout.
- Interfaces: defined by consumers, no speculative interfaces, compile-time
  compliance checks, never pointer-to-interface.
- Structs: named fields, no embedded mutexes, synchronization primitives
  not copied, zero values valid for mutexes.
- Errors: matched to use case (errors.New, fmt.Errorf, custom type),
  wrapped with %w, handled once, no "failed to" chains.
- Concurrency: every goroutine stoppable/waitable, no goroutines in init(),
  sync.WaitGroup or done channel, graceful shutdown required.
- Context: first parameter, never in structs, propagated through call chain.
- Testing: table-driven with give/want, t.Run sub-tests, loop var capture
  for t.Parallel(), httptest for HTTP.
- Collections: nil for empty slices, len(s)==0 for checks, defensive copy
  at boundaries, make() with capacity hints.
- Logging: log/slog for structured logging, no fmt.Println.
- Exit: os.Exit/log.Fatal only in main(), single run() error pattern.
- Linting: goimports, govet, golangci-lint (errcheck, staticcheck minimum).

RULES INTENTIONALLY OMITTED
---------------------------
- go.uber.org/atomic: stdlib sync/atomic sufficient for small services
- go.uber.org/goleak: extra dependency; lifecycle rules suffice
- _ prefix for unexported globals: Uber-specific, conflicts with _ discard
- Full revive linter config: covered by golangci-lint defaults
- Absolute ban on init(): legitimate uses exist for regexp compilation etc.

ABACUS-SPECIFIC ADAPTATIONS
----------------------------
- Concrete Registry instance (not global mutable map), immutable after startup
- No mutex needed for concurrent reads of immutable registry
- Function-based operation execution (ExecuteFunc) over strategy hierarchies
- No registry interface unless a consumer demonstrates need
- Graceful shutdown required (BLOCKER)
- log/slog for structured logging
- httptest for API-level tests
- golangci-lint in make lint / make verify
- No-op telemetry allowed but must not become ornamental architecture
